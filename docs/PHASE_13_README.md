## ผลทดสอบ

- `supabase/tests/phase13_social_enterprise.test.sql` ผ่านทั้งหมด:
  - ตั้งค่าได้เฉพาะ admin และสูตรค่าดำเนินการถูกต้อง
  - ตั้งสินน้ำใจได้เฉพาะเจ้าของ และผู้พบ/สาธารณะมองไม่เห็นก่อนคืน
  - ส่งมอบสำเร็จแม้ยังไม่จ่าย แล้วสินน้ำใจเปลี่ยนเป็น payable พร้อมออกคูปอง
  - ยืนยันการมอบ → ผู้พบเลือก → เจ้าหน้าที่บันทึกการโอน ทำงานครบ
  - ให้สินน้ำใจย้อนหลังได้ครั้งเดียวต่อคำขอ และจำกัดจำนวนคูปองต่อผู้พบ
  - รายได้บันทึกเพิ่มได้อย่างเดียว ยอดรวมถูกต้อง สาธารณะเห็นเฉพาะตัวเลขรวม และทุกขั้นมี audit
- ชุดทดสอบ phase 3–12 เดิมยังผ่าน (phase 11 เพิ่มตาราง SE ในการตรวจสิทธิ์)
- unit tests 67 รายการผ่าน (สูตรค่าดำเนินการตรงกับฐานข้อมูล, ห้ามถ้อยคำที่สื่อว่าเป็นเงื่อนไขการคืนของ)
- ทดสอบผ่าน browser กับฐานข้อมูลจริง (PostgREST):
  - เจ้าของตั้ง 500 บาทแล้วเห็น "ผู้พบได้รับ 490 บาท"
  - ยืนยันการมอบ 300 บาท ได้เลขอ้างอิง DEMO-…
  - ผู้พบเห็นคูปองและเลือกมอบให้โครงการ โดยไม่เห็นชื่อเจ้าของ
  - เจ้าหน้าที่บันทึกบริจาค และใช้คูปองได้ครั้งเดียว
  - admin บันทึกค่าบำรุง 12,000 บาท ยอดรวม 12,300 บาทถูกต้อง
  - guest เปิด `/impact` และ `/sponsors` ได้ แต่ `/admin/se` ต้อง login

## ข้อจำกัด

- **การชำระเงินเป็นโหมดสาธิต** ยังไม่มีเงินจริง (ต้องให้สถาบันอนุมัติและเลือกผู้ให้บริการก่อน)
- พันธมิตรไม่มีบัญชีในระบบ — การใช้คูปองให้เจ้าหน้าที่เป็นผู้ยืนยันด้วยรหัส
- สัญญาค่าบำรุงระบบ/พันธมิตรทำนอกระบบ ระบบแค่บันทึกรายรับเพื่อความโปร่งใส
