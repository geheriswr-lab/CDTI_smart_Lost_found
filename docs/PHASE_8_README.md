## Flow

```
ผู้พบแจ้งพบของ (with_finder / transferred_to_staff)
  → เจ้าหน้าที่รับของเข้า  /admin/custody        record_custody_transfer()  → custody_history
  → คำขอได้รับอนุมัติ (Phase 6–7, ไม่มีข้อพิพาท)
  → ผู้ขอได้แจ้งเตือน "ของพร้อมให้รับแล้ว" + เห็นสถานที่รับของ
  → ผู้ขอกด "ขอรหัสรับของ" → เห็นรหัส 6 หลัก **ครั้งเดียว** (หมดอายุ 48 ชม.)
  → ที่เคาน์เตอร์: เจ้าหน้าที่กรอกรหัส + ตรวจบัตร (บังคับสำหรับของมูลค่าสูง)   complete_handover()
  → handovers + custody_history (released_to_owner) + ของ = returned + รายการของหายที่เชื่อมไว้ = returned
  → แจ้งผู้ขอ "รับของคืนเรียบร้อย" · แจ้งผู้พบ "ของได้คืนเจ้าของแล้ว" (ไม่บอกว่าเป็นใคร)
```

## บทบาทที่แยกกันชัดเจน (หน้า /admin/handovers/[id])

ผู้แจ้งพบของ · ผู้ครอบครองปัจจุบัน · เจ้าหน้าที่ที่รับของเข้า · ผู้ขอรับ · ผู้ตรวจสอบ/อนุมัติ · ผู้ส่งมอบ · ผู้รับของจริง

## รหัสส่งมอบ (One-Time Handover Code)

- 6 หลัก สุ่มด้วย `gen_random_bytes` (CSPRNG) — ไม่ใช้ `random()`
- เก็บเฉพาะ **bcrypt hash** · plaintext แสดงให้ผู้ขอครั้งเดียวบนหน้าจอ ไม่อยู่ใน DB / แจ้งเตือน / audit log
- **ปิดช่องจาก Phase 1:** เดิมเจ้าหน้าที่อ่าน `code_hash` ได้ → รหัส 6 หลักมีแค่ 1 ล้านแบบ เดาย้อนจาก hash ได้
  ตอนนี้ไม่มีใครอ่านตาราง `handover_codes` ผ่าน API ได้เลย ตรวจรหัสเฉพาะใน `complete_handover()`
- หมดอายุ 48 ชม. · ใช้ได้ครั้งเดียว · กรอกผิด 5 ครั้ง = ล็อก (บันทึกทุกครั้งใน audit) · ขอรหัสใหม่ได้ไม่เกิน 5 ครั้ง (รหัสเก่าใช้ไม่ได้ทันที)
- รหัสผิดคืนค่าเป็นสถานะ ไม่ใช่ error → ตัวนับการกรอกผิดถูกบันทึกจริง (ถ้าใช้ exception จะถูก rollback)

## กฎที่บังคับใน DB

- ส่งมอบได้เฉพาะคำขอ `approved` ที่**ไม่มีคำขออื่นเปิดอยู่** (ข้อพิพาท) และของต้องอยู่กับเจ้าหน้าที่
- ของมูลค่าสูง (enhanced) → ต้องติ๊ก "ตรวจบัตรแล้ว" + เลือกประเภทบัตร · **เก็บแค่ประเภทบัตร ไม่เก็บเลขบัตร**
- เจ้าหน้าที่ที่เป็นผู้พบหรือผู้ขอของรายการนั้น ส่งมอบเองไม่ได้
- ปล่อยของ (`released_to_owner`) ได้ทางเดียวคือผ่าน `complete_handover()`
- `custody_history` / `handovers` client เขียนเองไม่ได้ · ผู้พบเห็นประวัติของชิ้นที่ตัวเองแจ้ง · ผู้รับเห็นบันทึกการรับของตัวเอง
- จุดส่งมอบ: admin เพิ่ม/แก้/ปิดใช้ได้ · **ลบไม่ได้** (ประวัติเก่ายังอ้างถึง) · รับของเข้าได้เฉพาะจุดที่เปิดใช้
- ของที่ส่งมอบแล้วหายจากหน้าสาธารณะ และขอรับซ้ำไม่ได้
